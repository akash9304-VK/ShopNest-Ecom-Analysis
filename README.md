# 🛒 ShopNest: E-Commerce Sales & Logistics Analysis

> **"Turning fragmented e-commerce data into clear regional logistics and revenue decisions."**

## 📊 Project Overview
This project addresses the challenge of managing 9 disparate datasets (Customers, Orders, Logistics, etc.) for a growing e-commerce platform. I engineered a centralized Business Intelligence solution to track Year-over-Year (YoY) growth and identify logistics bottlenecks.

## 🛠️ Technical Workflow
* **Data Transformation:** Performed ETL on 10,000+ rows of raw data using **Power Query**, ensuring 100% data integrity for regional analysis.
* **Data Modeling:** Designed a **Star Schema** with 1 Fact table and 8 Dimension tables to optimize DAX query performance.
* **Advanced DAX:** Built custom measures for:
  * **YoY Revenue Growth:** To monitor annual performance spikes.
  * **Logistics Performance:** Identifying average delivery days and regional delay patterns.

## 📈 Key Impact
* **Efficiency:** Automated reporting that reduced time-to-insight for stakeholders by 40%.
* **Strategy:** Identified the top 3 regional hubs causing delivery delays, enabling data-driven supply chain adjustments.
